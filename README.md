# Diabetes Linear Regression Pipeline

## Project Description

This project builds a machine learning pipeline for predicting diabetes disease progression using the Diabetes dataset available in Scikit-learn.

The pipeline performs data scaling using StandardScaler and applies Linear Regression to make predictions.

## Technologies Used

- Python
- Scikit-learn
- Linear Regression
- StandardScaler
- Pipeline
- Train-Test Split

## Steps Performed

1. Loaded the Diabetes dataset from Scikit-learn.
2. Separated features and target values.
3. Split the dataset into training and testing data.
4. Scaled the data using StandardScaler.
5. Created a machine learning Pipeline.
6. Applied Linear Regression.
7. Generated predictions on the test data.
8. Evaluated the model using Mean Squared Error (MSE) and R2 Score.

## Model Evaluation

The model is evaluated using:

- Mean Squared Error (MSE)
- R2 Score
